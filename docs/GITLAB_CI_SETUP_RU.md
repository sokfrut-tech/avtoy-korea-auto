# Подключение GitLab CI для AVTOY KOREA

Резервный pipeline уже подготовлен в корне репозитория: `.gitlab-ci.yml`.

## Что он делает
- использует Node.js 22;
- проверяет синтаксис `worker.js`;
- запускает регрессионный набор `node --test worker.test.mjs`;
- не выполняет деплой и не требует Cloudflare secrets.

## Подключение проекта в GitLab
1. Войдите в GitLab и откройте **New project** → **Import project** → **GitHub**.
2. Разрешите GitLab доступ к репозиторию `sokfrut-tech/avtoy-korea-auto` (репозиторий приватный, поэтому доступ должен включать его).
3. Импортируйте проект как приватный. Не делайте его публичным.
4. Откройте **Build → Pipelines** и убедитесь, что для проекта доступны GitLab-hosted runners.
5. После включения CI запустите pipeline на ветке `ci/gitlab-backup-runner-2026-11-14` либо импортируйте ветку вместе с репозиторием.

## Важные границы
- Существующие GitHub/Cloudflare secrets не копируются автоматически и не должны публиковаться в репозитории.
- Деплой в Cloudflare остаётся отключённым в GitLab до отдельной безопасной настройки переменных и release gate.
- Не включайте автоматический деплой только ради обхода проблем GitHub Actions.
- Слияние изменений в `main` и production выполняется только после успешного запуска проверок на реальном runner.
