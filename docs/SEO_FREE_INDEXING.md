# Бесплатная поисковая индексация AVTOY KOREA

## Цель

Подготовить публичный адрес Cloudflare Workers без покупки домена к обнаружению поисковыми роботами. Это не заменяет регистрацию собственного домена в Яндекс Вебмастере: Яндекс может не принять служебный поддомен workers.dev для подтверждения сайта.

## Что добавлено в Worker

- `/robots.txt`: разрешает обход публичного сайта и закрывает служебные маршруты `/admin`, `/api/` и `/telegram/`.
- `/sitemap.xml`: публикует главную страницу и отдельные URL подходящих опубликованных автомобилей.\n- `/cars/{id}`: отдаёт серверный HTML с уникальными title/description/canonical/Open Graph и галереей.
- Главная страница получает canonical URL, robots index/follow и Open Graph метаданные.

## Ограничения текущего сайта

Главный каталог всё ещё загружается браузером, но для опубликованных автомобилей добавлены отдельные серверно-рендеримые страницы. В sitemap попадают только записи из `car_approved:` с достаточно подробным описанием и фото/видео. Черновики, ожидающие модерации и пустые карточки исключаются. Если у записи некорректная дата публикации, sitemap просто не добавляет lastmod.

Дальнейшая задача — добавить тесты на серверные страницы и проверить их в preview: корректность URL, HTML escaping, исключение снятых/неполных карточек, выдачу фото и sitemap.

## Бесплатный порядок действий после проверки и публикации

1. Открыть `https://avtoy-korea-auto.sokfrut.workers.dev/robots.txt`.
2. Открыть `https://avtoy-korea-auto.sokfrut.workers.dev/sitemap.xml`.
3. Проверить главную страницу через публичную проверку URL Яндекса.
4. Не пытаться подтверждать в Вебмастере домен, который пользователь не контролирует.
5. Если Яндекс принимает URL как общедоступный источник, использовать его для проверки доступности; полноценный кабинет Вебмастера от этого не появляется.

## Безопасность

Никакие Telegram secrets, KV-данные, webhook-настройки, домены и production-конфигурация не меняются. Изменения не публикуются в production автоматически в рамках этой задачи.
