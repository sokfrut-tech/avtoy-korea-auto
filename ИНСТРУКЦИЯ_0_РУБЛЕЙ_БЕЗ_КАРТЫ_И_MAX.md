## Шаг 1. Подключить бота MAX параллельно к Telegram (0 ₽, 3 минуты)

В код `worker.js` уже встроен полноценный мост **Telegram + MAX** (`max-worker-bridge.js`). Когда клиент оставляет заявку на сайте, она уходит **и в Telegram, и в бот MAX**! Также из бота MAX вы можете смотреть заявки (`/orders`), проверять каталог (`/site`) и снимать объявления (`!unpublish <id>`).

1. В мессенджере **MAX** откройте официального **`@MasterBot`** (или `business.max.ru`) и создайте нового бота. Скопируйте его **токен**.
2. Откройте панель Cloudflare (`Workers & Pages` → `avtoy-korea-auto` → `Settings` → `Variables and Secrets`) и добавьте:
   - `MAX_BOT_TOKEN` = токен вашего бота из MAX
   - `MAX_WEBHOOK_SECRET` = любой придуманный вами пароль из букв и цифр (например `avtoy_max_secret_2026`)
   - `MAX_BOT_URL` = публичная ссылка на вашего бота в MAX вида `https://max.ru/...` *(тогда на сайте в шапке рядом с кнопкой «Мы в Telegram» сразу появится кнопка «Мы в MAX»!)*
3. Зарегистрируйте вебхук бота MAX одной командой в PowerShell (подставив ваш токен и секрет):
   ```powershell
   Invoke-RestMethod -Method Post -Uri "https://platform-api2.max.ru/subscriptions" `
     -Headers @{ Authorization = "ВАШ_MAX_BOT_TOKEN"; "Content-Type" = "application/json" } `
     -Body '{"url":"https://avtoy-korea-auto.sokfrut.workers.dev/max/webhook","secret":"avtoy_max_secret_2026","update_types":["message_created","bot_started"]}'
   ```
4. Напишите вашему новому боту в MAX команду **`/myid`** — он ответит вашим числовым `MAX User ID`.
5. Пропишите этот номер в переменную `MAX_ADMIN_IDS` в настройках Cloudflare Worker — готово! Теперь ваш бот в MAX и бот в Telegram работают синхронно.

## Шаг 2. Бесплатный перенос сайта, фото и видео в Россию за 0 ₽ (без банковской карты!)

Все ваши автомобили, отзывы, фотографии и видео уже скачаны, проверены по `SHA-256` и лежат в папке `standby/public` (битая тестовая карточка `car_1002326996766_3482` с текстом «исправить» отфильтрована автоматически).

### Вариант А — GitVerse Pages (0 ₽, без карты, без ИП, сервера в РФ)
1. Зайдите на российский сервис **[gitverse.ru](https://gitverse.ru)** (вход по обычной почте или Сбер ID, банковская карта НЕ нужна).
2. Нажмите **«Создать репозиторий»**, назовите его, например, `avtoy-korea` (тип: **Публичный** — в папке `standby/public` нет ни одного секрета или токена, только публичная витрина каталога).
3. Дважды нажмите на файл **`ОПУБЛИКОВАТЬ_НА_GITVERSE_БЕСПЛАТНО.bat`** в папке проекта и вставьте ссылку на созданный репозиторий.
4. В настройках репозитория на GitVerse откройте раздел **Pages**, выберите ветку `main` и корневую папку `/`.
5. Вы сразу получите быструю российскую ссылку вида `https://<ваш_логин>.gitverse.ru/avtoy-korea/` (или можете бесплатно привязать к ней свой домен `.ru`), которая открывается у всех провайдеров в РФ без VPN!

### Вариант Б — Yandex Cloud Free Tier (0 ₽/мес для физлица, если захотите облачную БД YDB)
> 4 000 ₽ в Yandex Cloud — это не плата, а бесплатный подарочный бонус от Яндекса новым аккаунтам. Сам тариф Free Tier (`Cloud Functions` + `API Gateway` + `YDB Serverless` + `Object Storage` до 1 ГБ) для обычного физлица стоит **0 ₽/мес**. Готовый адаптер уже лежит в файле `standby/yc-function.mjs`.

- **Проверить сайт на своём компьютере**: запустите `ЗАПУСТИТЬ_САЙТ_ЛОКАЛЬНО.bat` (или `npm run start:ru`) → откроется `http://localhost:8080`.
