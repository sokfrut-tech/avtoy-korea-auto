# Авто из Кореи, Китая и ОАЭ

Закрытый репозиторий для исходников сайта avtoy-korea-auto на Cloudflare Workers.

## Важно

- Не хранить Telegram-токены, пароли и другие секреты в репозитории.
- Секреты настраивать отдельно в Cloudflare Workers → Settings → Variables and Secrets.
- Перед публикацией проверять изменения и тестировать Worker.

Файл Worker будет добавлен отдельно после проверки актуальной версии исходников.
